# Premium report contract

Proposed price: USD 9.99 one-time. Disabled until provider approval, security review and successful sandbox tests. The first narrative adapter accepts only validated, allowlisted symbolic scores, locale and relationship type. Never sends birth dates, names, exact locations or raw charts by default. Future server implementation must derive scores from trusted computations, verify entitlements, apply rate limits and a token budget, validate structured output and reject claims of scientifically predicted relationship outcomes. Client-side scores are not trusted for paid fulfillment. Required sections: summary, five themes, strengths and challenges, actionable conversation prompts, limitations. Partial results need separate uncertainty-aware schema before premium support. No real model calls or payments in this revision.
