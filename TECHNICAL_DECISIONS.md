# Technical decisions (Claude)

- **TD-01 Offline geography fixture.** GeoNames-derived PyPI snapshots for local tests only; the deploy gate rejects fixture catalogs.
- **TD-02 Swiss Ephemeris as reference only** (approved with conditions): test fixture generation, never runtime.
- **TD-03 Births from 1900** (approved): pre-1970 flagged `historical-unverified`.
- **TD-04 Placidus omitted beyond ±66°**; whole-sign always available.
- **TD-05 Mean node only**; true node and Chiron deferred (Chiron needs a licence-compatible ephemeris).
- **TD-06 symbolic-0.1 stays default**; 0.2 is an opt-in candidate until CTO review.
- **TD-07 sharp (LGPL)** optional, not shipped with static export.
- **TD-08 Deploy build owns the catalog.** `npm run build` = GeoNames import → `next build` → artifact gate. A deploy cannot publish missing, partial (without explicit env) or fixture data. `build:app` is dev-only.
- **TD-09 Catalog format v2 (adaptive shards).** Per-country bucket count sized to a 200 KiB gzip target; only dense prefixes are deepened (independently, up to 16 chars); aliases trimmed per shard. World: 5,995 shards, max 204 KB gzip, well below 20,000 files.
- **TD-10 Unicode normalization:** Python and browser both drop every mark (M*), fixing Indic/Thai matching; parity is tested.
- **TD-11 Feature classes:** populated places (excluding abandoned/destroyed/historical) + ADM1–ADM5/ADMD.
- **TD-12 Streaming import** with a 3-country window (peak memory was 6.1 GB when all countries were held in memory).
- **TD-13 Wheels** render engine output only; glyphs may be nudged apart for legibility (order preserved), true degrees shown in tooltip and table.
- **TD-14 Checkout simulation** is provider-agnostic; real adapter must be server-side with signed idempotent webhooks; report input locked at order time.
- **TD-15 Three-layer interpretation.** Astronomy → Layer A evidence (ids, no text) → Layer B narrative (deterministic templates). A future LLM may only rewrite cited evidence; the validator enforces this.
- **TD-16 Knowledge base as versioned data** (`natal-kb-0.1`), gender-neutral Spanish (adjectives on feminine nouns), singular "they" in English, friendship-safe variants.
- **TD-17 Unknown-time robustness:** sign-level Moon only when it is stable all day; planets changing sign are dropped; aspects must hold at 00:00 and 23:59.
- **TD-18 No padding:** affinities and differences come only from real cross aspects; daily-life areas without evidence are labelled as topics to discuss.
- **TD-19 Scores de-emphasised:** symbolic-0.1 and 0.2 are unchanged and moved to the technical chapter; the narrative never shows scores.
- **TD-20 Premium story stored client-side** with the simulated order (localStorage) so recovery works offline. Server storage (Supabase) must apply data minimisation before launch.
- **TD-21 Unknown time is proven, not sampled (C-01):** DST-aware local-day window and conservative speed bounds (Moon 15.6, Mercury 2.3, Venus 1.35, Sun 1.05, Mars 0.85 °/day). Bisection runs to 60 s. Unproven facts are dropped. Only signs are reported for unknown times.
- **TD-22 Conjunctions are 'mixed' (C-02):** emphasis is constructive or intense; they never generate a tension card.
- **TD-23 Element balance (C-03):** coverage and ties are reported; the Sun's element breaks ties; there is no dominant element without evidence.
- **TD-24 0.2 parameters are exposed as hypotheses (C-04):** defaults are unchanged. Dimensions report `status` and `evidenceCount`; 50 is a mathematical midpoint.
- **TD-25 Semantic grounding (C-05):** the validator applies lexicon checks on signs, bodies, aspects, tone, certainty and prediction against the cited evidence. These are necessary, not sufficient; editorial review is still required before any LLM is activated.
- **TD-26 Library variants:** any knowledge-base text field may be an array; the variant is chosen deterministically from the evidence id.
- **TD-27 Preview verification:** every PR commit's Cloudflare preview is tested by GitHub Actions (no manual step needed for Gate 1 evidence).
- **TD-28 Geography release cycle (block 3):** deploy builds install a SHA-256-pinned catalog bundle (`geography.lock.json`) and never silently fall back to different data. A new catalog needs a `geo-*` release, which a person starts (it publishes public content). With no lock file the old rebuild behaviour stays.
- **TD-29 Personal data never enters the repo:** fixtures use generated fictional dates. The guard test reads its patterns from a founder-owned secret, so no value is committed. Incident handling: PRIVACY_INCIDENT.md, written without values.
- **TD-30 One reading per real contact:** narrative ignores knowledge-base aliases and builds a contact-specific reading from the roles of both points and their signs. Card titles are unique per reading.
- **TD-31 Three relationship groups:** harmonious → symbolic affinities; conjunctions (mixed) → intense or mixed connections (possibility + care, never stated as fact); square/opposition → differences. The free edition keeps 5 cards (the intense card takes an affinity slot).
- **TD-32 symbolic-0.2 parameter sets are versioned** (`candidate`, `sym-a`, `sym-b`, `sym-c`). 0.1 stays frozen. Friendship excludes attraction and renormalises the remaining weights. No set is tuned toward a mean.
- **TD-33 LLM scope and budget:** only chapters 3–8 may be rewritten. Budget target USD 0.05 and cap USD 0.10 per report, retries included (worst case). Over the cap or over `maxOutputTokens` → deterministic generator. Prices are parameters, never hard-coded quotes.
